# Sorad

Sorad adalah aplikasi mobile-first frontend-only berbasis **React + Vite** untuk edukasi dan referensi cepat onkologi radiasi.

## Fitur utama
- Home dashboard + statistik belajar
- Learn hub: Quiz, Cards, Atlas, Terms, Guide, OAR
- Tools hub: Calc, History, Bookmarks terpadu
- Notes pribadi (CRUD, template, export/import JSON)
- Global search lintas konten
- Seluruh data berjalan lokal (JSON + localStorage)

## Jalankan lokal
```bash
npm install
npm run dev
```

## Build production
```bash
npm run build
```

## Deploy
Siap deploy ke Vercel sebagai static Vite frontend.

## Disclaimer
Aplikasi ini hanya untuk edukasi, referensi, dan pencatatan pribadi, **bukan** alat keputusan klinis resmi.
